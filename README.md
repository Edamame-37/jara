Aplikasi web JARA (Advanced Todo List) mencakup tiga modul spesifikasi kebutuhan fungsional (SRS), yaitu 
SRS-01 (Admin & User Management) bagi administrator untuk menambah dan menghapus akun pengguna dalam sistem;
SRS-02 (Task & Project Management) yang memfasilitasi pengguna untuk membuat dan mengelompokkan daftar (list/project), menyusun tugas, menetapkan tingkat prioritas, menentukan tenggat waktu (deadline), serta menandai tugas yang telah selesai; serta 
SRS-03 (Collaboration & Progress Tracking) yang memungkinkan pemilik daftar mengundang pengguna lain ke dalam daftar tugasnya untuk dikerjakan bersama sekaligus memantau persentase progres penyelesaian tugas secara terukur.
